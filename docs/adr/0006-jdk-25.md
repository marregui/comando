# 6. JDK 25

| Date | Status | Decided by |
|---|---|---|
| 2026-10-12 | accepted | Miguel, on the defaults proposed in the plan review |

## 1. Context

The sibling project `jfr` targets JDK 25. comando uses virtual threads, sealed types, record patterns and `List.getFirst`.

## 2. Decision

JDK 25 toolchain for every module; the DMG bundles a JDK 25 runtime.

## 3. Consequences

Users of the DMG need no installed JDK. Building needs JDK 25.
