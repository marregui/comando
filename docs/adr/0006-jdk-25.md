# 6. JDK 25

| Date | Status | Decided by |
|---|---|---|
| 2026-10-12 | accepted | Miguel |

## 1. Context

The sibling project `jfr` targets JDK 25. comando uses virtual threads, sealed types, record patterns and
`List.getFirst`.

## 2. Decision

A JDK 25 toolchain for every module. The disk image bundles a JDK 25 runtime.

Miguel decided, on the default proposed in the review of the design plan.

## 3. Consequences

Users of the disk image need no installed JDK. Building needs JDK 25.
